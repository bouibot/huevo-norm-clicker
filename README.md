# huevo invite-clicker (Telegram-бот)

Кликер копилки [huevo.su](https://huevo.su) **по приглашениям**: попасть в бота можно
только с одноразовым кодом приглашения, который создаёт владелец через админ-панель.
Клиент добавляет свой логин/пароль от huevo.su, решает капчу в чате - ферма на твоём VPS
фармит его копилку 24/7. **Комиссий нет** - весь фарм остаётся клиенту.

Ядро взято из референсной фермы (`huevo-multi-clicker-v2` → `../huevo-multi-clicker-v2`):
антибот 418 (XOR-Advance `hchk`), логин с капчей (`data-k` → `hv`), POST `/api/clicker`
(batch ≤ 400, MIN_GAP 8 с), дневной кап «full», автосохранение/переиспользование cookies.

## Как попасть в бота (клиенту)

1. Получить у владельца код приглашения вида `HUEVO-A2B3C4D5E6`.
2. Открыть бота, прислать код **сообщением** (или `/start КОД`, или `/code КОД`).
3. Код одноразовый: после активации бот пересылать его нельзя. Срока действия нет.
4. Дальше: `/add` → логин huevo.su → пароль → капча-фото → фармит.

До активации бот не даёт ничего: ни меню, ни добавления аккаунтов.

## Владельцу: коды приглашений

- `/admin` → **🎟 Коды** - панель кодов:
  - 🎲 **Сгенерировать код** - случайный `HUEVO-XXXXXXXXXX` (алфавит без похожих символов);
  - ✍️ **Свой код** - свой текст (4-32 символа: латиница/цифры/дефис), удобно раздавать «по имени»;
  - 🚫 нажатие на свободный код - отзыв (юзер больше не активирует).
- Список показывает: кто активировал (юзер・когда), свободные, отозванные.
- О каждой активации придёт уведомление.
- Владелец, админы и их аккаунты - мимо гейта: могут пользоваться ботом без кода.

## Функции

- 📥 Клиент в боте: `/add` → логин → пароль → **капча фото** → код ответным сообщением.
- 🍀 Постоянный фарм: кликаем `400 × раз в ~8.5 с`, автоперелогин при смерти сессии.
- 🔑 Перезапуск бота: все аккаунты и сессии уже в SQLite; если при старте сессия
  мертва, бот шлёт клиенту кнопку «Перелогиниться» - по нажатию приходит капча.
  Всё сохраняется в `data/clicker.db`.
- 🛠 Админ (`/admin`): коды, все аккаунты, рассылка, управление админами.
- 📢 `/broadcast` - рассылка HTML-текста всем юзерам бота с предпросмотром.
- 🔔 Уведомления: успешный вход, запрос капчи, проблемы сети, активация кодов.

## Права в боте

| Кто | Что может |
|-----|-----------|
| Неактивирован юзер | только ввод кода приглашения |
| Клиент (по коду) | `/add`, `/accounts`, капчи, смена пароля своего аккаунта |
| Админ (из БД) | `/admin` (статистика), `/broadcast`, `/admins` |
| Владелец (`.env OWNER_ID`) | всё выше + создание/отзыв кодов приглашений, `/adminadd`, `/admindel` |

Если `OWNER_ID` не задан и в БД нет владельца - первый, кто вызовет `/admin`,
станет владельцем (claim).

## Деплой на VPS

```bash
# Node.js 22.5+ (лучше 24 LTS): https://nodejs.org
git clone <твой-репо> huevo-invite-clicker
cd huevo-invite-clicker
npm install

# конфиг: скопируй пример и заполни (BOT_TOKEN, OWNER_ID) - .env в гит не попадает
cp .env.example .env
nano .env

# старт вручную (проверка)
npm start

# автозапуск через systemd (юнит в deploy/huevo-invite-clicker.service):
sudo tee /etc/systemd/system/huevo-invite-clicker.service > /dev/null < deploy/huevo-invite-clicker.service
sudo systemctl daemon-reload
sudo systemctl enable --now huevo-invite-clicker
journalctl -u huevo-invite-clicker -f
```

> ⚠️ Токен бота и пароли аккаунтов - секреты: `.env` и `data/` в `.gitignore`;
> перед push проверь `git status`.

> ⚠️ **Важно про токен:** `.env` сейчас заполнен тем же BOT_TOKEN, что у
> `huevo-multi-clicker-v2`. Запустишь оба одновременно - Telegram отдаст getUpdates
> только одному (гонка апдейтов). Используй либо один проект, либо дай новому
> отдельный токен через @BotFather.

## Как это работает внутри

| Файл             | Что делает |
|------------------|------------|
| `src/config.mjs` | .env, константы (паузы кликов 8.4 с, капча-таймаут 10 мин), генератор кодов |
| `src/db.mjs`     | SQLite (встроенный `node:sqlite`): аккаунты, cookies, юзеры, админы, **invites** |
| `src/site.mjs`   | HTTP-клиент huevo.su: антибот 418, логин, капча `/captcha/refresh/login`, кликер |
| `src/engine.mjs` | Цикл фарма на аккаунт: сессия → клик → пауза; логины сериализуются |
| `src/bot.mjs`    | grammY: гейт по кодам, диалоги, капча-очередь (FIFO на чат), меню, панель кодов, рассылка |
| `src/index.mjs`  | Сборка всего вместе + защита от второго экземпляра |

## Ограничения сайта (учтено)

- `MIN_GAP_SECONDS = 8000` между кликами, `MAX_BATCH = 400` за запрос.
- Дневной кап: `/api/clicker` отдает `{"capped":true,"error":"full"}` - не ошибка, ждём сброса (10 мин циклы).
- Капча обязательна только на логине; пока жива кука `session` - капча не нужна (cookies в БД).
- После нескольких неверных входов сервер лочит логин по IP (~5 мин) - логины идут строго по очереди с паузами.

## Важно

- Пароли клиентов хранятся в SQLite открытым текстом (нужно для автоперелогина) - держи VPS под замком.
- Капча решается **вручную клиентом в боте**; если клиент оффлайн, аккаунт «спит» 30 мин и спрашивает снова.
- Коды отзываются владельцем (кнопка 🚫 в панели кодов); активированный код отозвать уже нельзя.
